# AI Customer Support Coach — Polished Streamlit UI

## Run
1. Open Command Prompt in this folder.
2. Activate your virtual environment:
   venv\Scripts\activate
3. Install:
   pip install -r requirements.txt
4. Start:
   streamlit run app.py
5. Open http://localhost:8501

Enter your Groq API key under **Settings**.

The UI accepts arbitrary customer sentences and dynamically analyzes sentiment, emotion, intent, urgency, escalation risk, key issue and suggested reply. Agent responses are evaluated for tone, empathy, clarity, accuracy and actionability. Patience, trust and promise tracking update from the live conversation.
